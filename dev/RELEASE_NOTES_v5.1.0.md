# ZenDesktop v5.1.0

相对 v5.0.0。再次部署不会关掉已打开的 mod，也不会覆盖你改过的设置。

## 新增

- 可选 mod「桌面时钟」1.4.0，默认关闭。画在桌面图标后面，不挡图标。关掉拖动后不吃鼠标。
- 时钟、日历、资源占用拆成三块，各自开关、各自大小、各自拖动。
- 17 种样式加自定义。颜色改成下拉：跟随样式、白、黑、浅灰、红、橙、金黄、绿、青、蓝、紫、粉、跟随系统强调色、自定义。以前填过的色值会按自定义保留。
- 日历样式：整月、紧凑整月、本周、今天、一行日期。今天用强调色标出，可显示农历。紧凑整月不显示农历。
- 资源占用可单独勾选 CPU、内存、GPU、网速。没勾的不采样，四项都关则不显示这一块。读不到 GPU 时显示 `--`。
- 打开「拖动调整位置」后，拖框中间移动，拖四个角连续改大小（20-800），松手记住。改了大小百分比，以百分比为准。重置只清位置，不清大小。
- 装了 Wallpaper Engine 时，时钟会保持在壁纸上面。

## 改进

- 任务栏美化 4.3.0：可调任务栏高度和图标大小，默认 0 表示不改。资源管理器重启后会自动补挂任务栏、托盘和音量浮窗。
- 文件管理器美化 1.7.4：打开窗口不再先闪一下。选中改为半透明深色玻璃。控制面板顶部黑条改为透明。和上游 Explorer Styler 冲突时少弹窗，请关掉上游 mod。
- 设置美化 4.2.6：跳过「个性化 → 背景」页的样式，减轻 Win11 26H2 闪退。修复白底卡片盖住白色文字。
- 窗口动画 1.6.3：去掉「零雾开窗」。
- 部署脚本：双击不再闪退，中文不再乱码。再次部署只覆盖有改动的 mod。

## 下载

| 文件 | 适合谁 |
| --- | --- |
| `ZenDesktop_OneKeyDeploy_v5.1.0.zip` | 大多数人。带 Windhawk 联网安装器 |
| `ZenDesktop_OneKeyDeploy_v5.1.0_Offline.zip` | 网络差。带离线安装器 |
| `ZenDesktop_OneKeyDeploy_v5.1.0_Online.zip` | 已经装好 Windhawk |

## 安装

1. 解压下载的 zip。
2. 双击 `deploy.bat`，在权限提示里点「是」。
3. 打开 Windhawk。新装的 mod 默认关闭，按需打开。桌面时钟在可选 mod 里。
4. 全部调好后，建议重启一次电脑。
