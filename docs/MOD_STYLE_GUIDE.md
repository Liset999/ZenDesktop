# ZenDesktop Mod 文字规范

本规范约束所有 ZenDesktop Windhawk mod 中用户能看到的文字：元数据（`@name`、`@description`）、说明（`==WindhawkModReadme==`）和设置界面（`==WindhawkModSettings==`）。新 mod（包括 `zen-taskbar-lyrics`）和后续改动都按此执行。

## 1. 硬性约束

规范化只改显示文字，不改行为：

- 不改设置的键名、选项值、默认值、类型和层级结构（层级决定 `Wh_GetIntSetting(L"group.key")` 的路径）。
- 选项标签只改 `- 值: 标签` 中冒号右侧的标签，值保持原样。
- 不删除、不改写 GPL / MIT 许可声明和 `@author`、`@github` 等作者信息。
- 只改文字时把补丁版本号加一（`x.y.z` → `x.y.z+1`）；上游版本号不是三段式的，在末尾追加 `.1`。
- 提交前运行校验脚本，确认设置的键、值、默认值和代码部分与改动前完全一致。

## 2. 元数据

```
// @name              ZenDesktop: 任务栏美化
// @name:zh-CN        ZenDesktop: 任务栏美化
// @description       Acrylic taskbar with adjustable blur, opacity and color.
// @description:zh-CN 为 Windows 11 任务栏提供亚克力与透明背景，模糊、不透明度和颜色可调。
```

- `@name` 和 `@name:zh-CN` 都写成 `ZenDesktop: <中文名>`，中文名 2–8 个字，不带英文括注。
- `@description` 写一句英文，`@description:zh-CN` 写一句中文，以句号结尾。只说做什么，不写“高质量”“深度”“极致”等形容词，不写感叹号。
- 基于他人 mod 的，在说明的“致谢与许可”里注明，不必写进 `@description`。

## 3. 说明（Readme）

中文在前，章节固定为以下顺序，没有内容的章节可以省略：

1. `# ZenDesktop: <中文名>`，下面一段话简介（2–3 句）。
2. `## 功能`：要点列表，每条一句。
3. `## 设置说明`：按设置界面的顺序，说明重要或不直观的设置；简单开关不必逐条写。
4. `## 兼容性与已知问题`：适用系统、注入的进程、与其他 mod 或程序的冲突、需要用户手动处理的事项。
5. `## 更新日志`：只列最近 3–5 个版本，每版 1–3 条，格式 `- **x.y.z**：内容。`
6. `## 致谢与许可`：原作者、原版链接、许可证、ZenDesktop 修改内容摘要，以及开发者链接。
7. （可选）`## 附录：原版说明（英文）`：上游的技术文档（如控件样式语法）篇幅大、更新频繁，可原样保留英文，放在最后并注明来源。

写法：

- 不用 emoji，不用“👨‍💻”“⚠️”之类的装饰符号做标题。
- 中文使用全角标点（，。：；「」（）），中英文、中文与数字之间加一个空格。
- 代码、进程名、设置值用反引号，例如 `explorer.exe`。
- 不写营销用语，不写“强烈推荐”“全网首发”之类的话。

## 4. 设置界面

每一项都写四个字段：

```yaml
- blurPreset: 30
  $name: "Blur"
  $name:zh-CN: "模糊"
  $description: "Background blur strength, 0–60. Larger is blurrier."
  $description:zh-CN: "背景模糊强度，范围 0–60，数值越大越模糊。"
```

- `$name` / `$description` 写英文（给非中文界面），`$name:zh-CN` / `$description:zh-CN` 写中文。简单的子项（如控件样式里的「目标控件」「样式」）可以只有名称。
- 名称是名词短语，不带标点、不带 emoji、不带英文括注。带单位的写在名称末尾：`时长（毫秒）`、`宽度（像素）`、`延迟（秒）`。
- 描述先说作用，再写范围，最后写默认值：`……，范围 0–100。默认 23。`开关写「默认开启」或「默认关闭」；下拉写「默认为 <标签>」。
- 范围用 en dash：`0–100`，不写 `0-100` 或「0 到 100」。
- 只在某项开启时才生效的，写「仅在开启「X」后生效」。
- 高级项名称以「高级：」开头，例如「高级：样式常量」，描述末尾写「一般无需修改。」
- 同一组相关设置用名称前缀表达（例如「文件夹：模糊」「最大化时：不透明度」）。已有的扁平设置不能为了分组改成嵌套对象，因为那会改变设置路径、让用户已保存的设置失效；新 mod 可以直接用嵌套对象分组。

### 选项标签

- 统一只写中文。数值预设写成 `数值：说明`，例如 `30：较强`、`50%：适中`。
- 带解释的样式写成 `名称：解释`，例如 `灭霸响指：化为微粒消散`。
- 例外：社区主题名（`theme` 下拉）保留原名，写成 `中文名（原名）`，方便对照上游主题页面；原名和中文相同或已包含在中文里时只写中文。
- 推荐项在标签末尾加「（推荐）」，不加其他标记。

## 5. 统一用语

| 概念 | 统一写法 | 不再使用 |
| --- | --- | --- |
| Opacity（数值越大越不透明） | 不透明度 | 浓度、填充浓度、透明度 |
| Blur | 模糊 | 毛玻璃模糊度、模糊度 |
| Luminosity | 亮度 | 亮度通透度 |
| Tint | 色调 | 色彩、着色 |
| Text color | 文字颜色 | 字体颜色 |
| Dark / Light / System | 深色 / 浅色 / 跟随系统 | 暗色、亮色、暗黑 |
| 主题自带值 | 主题默认 | 风格默认 |
| Theme | 主题 | 视觉风格 |
| 毫秒、像素、秒 | 毫秒、像素、秒 | ms、px（中文文本中） |

### 共用选项

- 背景颜色：主题默认、系统强调色、透白、雾灰、深黑、海蓝、极光青、玫瑰粉、酒红、森林绿、皇家紫、落日橙、香槟金、莫兰迪绿。
- 文字颜色：主题默认、白色、深色、跟随系统、红色、绿色、蓝色、黄色、橙色、紫色、粉色、青色。
- 模糊：`0：不模糊`、`10：轻微`、`20：中等`、`30：较强`、`45：强`、`60：最强`。
- 不透明度：`0%：完全透明`、`10%：很薄`、`25%：较薄`、`50%：适中`、`75%：较厚`、`90%：很厚`、`100%：完全不透明`。
- 亮度：`0：最低`、`20：低`、`25：较低`、`50：中`、`75：较高`、`100：标准`、`125：高`、`150：最高`。
- XAML 诊断冲突处理：弹窗询问、阻止其他程序、允许其他程序。

## 6. 作者信息与捐助（说明开头）

- 每个 mod 的说明（`==WindhawkModReadme==`）**第一段**固定为作者块，放在标题和其他任何内容之前；赞赏码用 HTML `<img width="160">` 缩小显示。内容逐字统一：

```markdown
> **作者：Lanbo**
> [B站](https://space.bilibili.com/1280632999) · [抖音](https://v.douyin.com/Isl7QPpKZZ4/) · [爱发电](https://ifdian.net/a/Lanboo)
>
> 微信赞赏：<br><img src="https://raw.githubusercontent.com/Liset999/ZenDesktop/v4.2-draft/docs/donate-wechat.png" alt="微信赞赏码" width="160">
```

- 基于他人 mod 的，在作者块之后紧跟一行原作者说明（如窗口动画：`> 原作者：**ReDrag**……`）。
- 说明末尾不再单独写 `## 捐助支持` 一节，避免重复。

- 元数据中加入 Windhawk 支持的 `@donateUrl`，指向爱发电：`https://ifdian.net/a/Lanboo`。基于他人 mod 且原版已有 `@donateUrl` 的（如窗口动画），保留原作者的链接，不替换；其说明开头的作者块照常写爱发电与微信赞赏码。
