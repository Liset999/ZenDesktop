# Third-party optional mods / 第三方可选 Mod

这些 Mod 随 ZenDesktop 一键部署可选安装（文件名加 `local@` 前缀）。**首次部署默认关闭**（`Disabled=1`）。版权归各原作者；详见各自 `.wh.cpp` 头注释。

These mods are bundled for optional install (filename gets a `local@` prefix). First deploy leaves them disabled. Copyright remains with each author; see the license header inside each `.wh.cpp`.

|---|---|---|---|

| Windows Animations（ZenDesktop: 窗口动画，基于 v1.3.7+ 修改） | ReDrag；macOS Genie：Abdullah Masood / Potassiumuncher | MIT | https://windhawk.net/mods/windows-animations |
