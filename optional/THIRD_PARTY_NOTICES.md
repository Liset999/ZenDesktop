# Third-party optional mods / 第三方可选 Mod

These mods are bundled (Windows Animations is modified by ZenDesktop, see its readme; the others are unmodified) (only the file name gets the `local@` prefix) from
https://github.com/ramensoftware/windhawk-mods. They are installed only if you opt in during deploy.
以下 Mod 原样收录（仅文件名加 `local@` 前缀），只有在部署时选择安装才会启用。

| Mod | Author | License | Source |
|---|---|---|---|
| Wobbly Windows v0.115 | lalimatyus (https://github.com/lalimatyus) | GPL-3.0-only | https://windhawk.net/mods/wobbly-windows |
| Windows Animations v1.3.7 | ReDrag (https://github.com/redrag2105) | MIT | https://windhawk.net/mods/windows-animations |
| macOS Minimize Animation (merged into Windows Animations 1.4.0 as the "macOS Genie" style; ZenDesktop modifications) | Abdullah Masood (https://github.com/Abdullah-Masood-05); Direct2D genie engine by Potassiumuncher (https://github.com/Potassiumuncher) | MIT | https://windhawk.net/mods/macos-minimize-animation |
